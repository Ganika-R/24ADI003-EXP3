This experiment implements Multilinear Regression and Polynomial Regression models to understand relationships between variables and make predictions. The models are trained, evaluated, and optimized using different techniques such as feature scaling, regularization, and model evaluation metrics (MSE, RMSE, R² Score).

Scenario 1: Multilinear Regression

Dataset Link:
https://www.kaggle.com/datasets/spscientist/students-performance-in-exams

Description:
The Student Performance dataset contains information about students’ academic results and factors that influence their performance. Features such as study hours, attendance percentage, parental education level, test preparation course, and sleep hours are used to analyze student outcomes. In this experiment, the average of math, reading, and writing scores is used as the target variable. Multilinear regression is applied to predict student performance based on multiple influencing factors.

Scenario 2: Polynomial Regression

Dataset Link:
https://www.kaggle.com/datasets/uciml/autompg-dataset

Description:
The Auto MPG dataset contains vehicle characteristics and their fuel efficiency. In this experiment, engine horsepower is used as the input feature and Miles Per Gallon (MPG) is used as the target variable. Since the relationship between horsepower and fuel efficiency is non-linear, polynomial regression is used to model and predict the MPG values.
